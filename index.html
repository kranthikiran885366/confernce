About The Event

The 3rd International Conference on Networks and Soft Computing (ICNSoC 2027) aims to bring together scholars working in this field to exchange their expertise and experience. Topics of current interest will be presented at this conference in order to provide a comprehensive view of the latest advancements in computer science and engineering. The scope includes Networks, Wireless and Ad-hoc sensor networks, soft computing, machine learning, computer vision, image processing, natural language processing, deep learning, artificial intelligence, artificial neural networks, mobile application development, and Internet of Things, among other topics. Conference participants are expected to gain relevant knowledge and a better understanding of computer science applications in various fields.

CALL FOR PAPERS

Track 1: Next-Generation Networks and High-Performance Computing

  • 6G and Beyond: Challenges, Architectures, and Use Cases
  • Software-Defined Networking (SDN) and Network Function Virtualization (NFV)
  • Edge and Fog Computing for Smart Networks
  • Green Networking and Energy-Efficient Protocols
  • High-Performance Computing (HPC) for Large-Scale Network Simulations
  • AI-Driven Network Management and Traffic Optimization
  • Digital Twin for Network and Infrastructure Modelling
  • Quantum Networking and Communication

Track 2: Wireless Communications, IoT, and Edge Computing

  • Intelligent Wireless Networks and Smart Antenna Technologies
  • 5G/6G technologies
  • Internet of Things (IoT)
  • Security and Privacy in IoT and Edge Computing Systems
  • UAV and Satellite-Based Wireless Communication Networks
  • Edge Computing and Federated Learning
  • Block-chain for Secure IoT Applications
  • Smart Cities and Intelligent Transportation Systems

Track 3: Cybersecurity, Block-chain, and Trust Computing

  • Intrusion Detection and Prevention
  • Block-chain and Distributed Ledger Technologies for Security
  • Zero Trust Security Models for Next-Gen Networks
  • Privacy-Preserving Machine Learning for Cybersecurity
  • Post-Quantum Cryptography and Secure Key Management
  • Secure Authentication and Access Control in Cloud & IoT
  • Cyber-Physical System (CPS) Security and Resilience

Track 4: Soft Computing and Computational Intelligence

  • Hybrid Soft Computing Techniques (Neuro-Fuzzy, Genetic-Fuzzy, etc.)
  • Evolutionary and Swarm Intelligence for Large-Scale Optimization
  • Reinforcement Learning for Autonomous Systems
  • Fuzzy Logic for Control and Decision-Making
  • Deep Learning and Soft Computing for Pattern Recognition
  • Soft Computing in Big Data Analytics and Cloud Computing
  • Adaptive Learning and Explainable AI (XAI) Models

Track 5: Machine Learning, and Deep Learning Applications

  • AI for Network Optimization and Traffic Prediction
  • Deep Learning for Signal Processing and Wireless Networks
  • Large-Scale Distributed AI for Cloud and Edge Computing
  • Natural Language Processing (NLP) for Social Media Analysis
  • Transformer Models for Image, Video, and Speech Processing
  • AI-Powered Robotics and Autonomous Systems
  • Transfer Learning and Few-Shot Learning for Real-World AI Applications
  • Federated Learning and Privacy-Aware AI Models

Track 6: Computer Vision and Multimedia Processing

  • Deep Learning for Image and Video Processing
  • AI-Powered Object Detection and Scene Understanding
  • Computer Vision for Smart Surveillance and Intelligent Transportation
  • AI-Based Medical Imaging and Disease Diagnosis
  • Augmented Reality (AR) and Virtual Reality (VR) in Vision Applications
  • Vision-Based Traffic and Road Safety Systems
  • High-Performance Computing for Real-Time Computer Vision
  • Multi-Modal Learning for Vision and Language Processing

Final Paper Guidelines
The final paper should be written in English with a maximum paper length of six printed pages including figures.

Upload here

Authors should abide by the ICNSoC-27 guidelines while in the manuscript submission:

  1. All the papers will be double-blind peer-reviewed for scientific quality by the reviewers and the Technical Program Committee. So authors must not include their names and addresses in the papers.
  2. Papers must be submitted electronically, in PDF format only.
  3. All references must follow the IEEE format of referencing.
  4. Authors should follow the IEEE Plagiarism policies.
